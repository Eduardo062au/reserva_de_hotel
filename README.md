# Sistema de Reservas de Hotel

## O que é?
Sistema que gerencia reservas de quartos de um hotel.

## Como executar
1. Instale as dependências:
   npm install

2. Execute o projeto:
   npm start

## O que o sistema faz
- Registra novas reservas de quartos
- Cancela reservas existentes
- Consulta se um quarto está reservado ou disponível
